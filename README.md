# Практическая работа №2

CSS, адаптивная верстка и SCSS. Организация стилей.

## Описание

Разработка адаптивного каталога учебных товаров по данным из dataset. 

## Исходные данные

- `dataset/catalog.csv` — исходные названия товаров, категории, цены и рейтинги.
- `dataset/theme.json` — исходные цвета, базовый радиус и размер отступов.
- `dataset/assets/` — исходные изображения товаров.

Папка `dataset` сохранена без изменений. Рабочие копии данных находятся в `data`, изображения для страницы — в `images`.

В HTML вручную перенесены первые 12 товаров из catalog.csv: названия, категории, цены и рейтинги.

## Раскладка и адаптивность

Основная раскладка и сетка карточек выполнены через CSS Grid. В шапке используется Flexbox.

При ширине экрана 900 px и меньше панель фильтров перемещается над товарами. При ширине 600 px и меньше карточки располагаются в одну колонку, а элементы шапки — друг под другом.

## Фильтрация

Категория выбирается переключателями. CSS-селектор `:has()` определяет выбранную категорию и скрывает неподходящие карточки по атрибуту `data-category`. Пункт «Все товары» показывает все 12 карточек.

## Организация SCSS

Исходные стили находятся в папке `scss`:

- `_variables.scss` — цвета из `theme.json`, отступы, радиус, ширина контейнера и пороги адаптивности.
- `_functions.scss` — функция `space()`, рассчитывающая отступы от базового значения 16 px.
- `_mixins.scss` — миксин `surface()`, используемый для оформления карточек, фильтров и информационного блока.
- `_base.scss` — общие правила страницы.
- `_components.scss` — оформление отдельных компонентов.
- `_layout.scss` — расположение блоков, сетка и медиазапросы.
- `styles.scss` — главный файл, подключающий остальные части через `@use`.

Файлы с подчёркиванием в начале имени называются partial-файлами. Они разделяют стили на логические части и подключаются к основной сборке.

Используется короткая вложенность. Например, `&__title` внутри `.card` превращается в `.card__title`.

Переменная SCSS, например `$accent`, обрабатывается при сборке и заменяется значением в итоговом CSS. CSS custom property, например `--accent`, остаётся в CSS и обрабатывается браузером через `var()`. [Переменные Sass](https://sass-lang.com/documentation/variables/), [CSS custom properties](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/--*).

## Запуск и сборка

Для сборки требуются Node.js LTS и npm.

После клонирования репозитория откройте терминал в корне проекта и установите зависимости по `package-lock.json`:

```bash
npm ci
```

Выполните разовую сборку:

```bash
npm run build
```

Откройте `index.html` в браузере или через Live Preview в VS Code.

Для автоматической сборки при изменении SCSS:

```bash
npm run watch
```

Остановка режима наблюдения — `Control + C`.

Команды сборки записаны в `package.json`. Результат сохраняется в `css/styles.css`, который подключён к HTML. Изменения оформления выполняются в SCSS, после чего обновляется CSS.

В репозитории сохраняются исходные SCSS и готовый CSS. Папка `node_modules` исключена через `.gitignore`.

## Результаты ручных проверок

- Разовая сборка SCSS завершилась без ошибок.
- Режим `watch` автоматически обновляет CSS после изменения переменной цвета.
- Фильтры показывают товары выбранной категории; «Все товары» возвращает все 12 карточек.
- На ширине 375 px фильтры находятся сверху, карточки расположены в одну колонку.
- На ширине 768 px фильтры находятся сверху, карточки расположены в три колонки.
- На ширине 1440 px фильтры находятся слева, карточки расположены в четыре колонки.
- На проверенных ширинах горизонтальная прокрутка страницы не обнаружена, текст и изображения помещаются внутри карточек.
